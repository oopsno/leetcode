## 3. 核心模板速查

### 3.1 股票状态机

```text
dp0 = max(dp0, dp1 + price)   # 今天收盘不持股
dp1 = max(dp1, dp0 - price)   # 今天收盘持股
```

- 0121：只能交易一次，dp1 从 -price 转移。
- 0122：无限次，最终等价于所有正差分之和。
- 含冷冻期：拆分 dp0 为“可买”和“冷冻”。
- 含手续费：卖出时减 fee。

### 3.2 BST 中序模板

```text
dfs(node):
    if node == null: return
    dfs(node.left)
    # 处理 prev 和 node
    prev = node
    dfs(node.right)
```

- 0098：检查 `prev.val < node.val`。
- 0530 / 0783：更新相邻差最小值。
- 0501：统计连续频率。
- 0538：反中序，累加前缀和。

### 3.3 树形 DP 模板

```text
dfs(node) -> 状态元组:
    if node == null: return 基线状态
    left = dfs(node.left)
    right = dfs(node.right)
    根据 left / right 推导当前状态
    return 当前状态
```

- 0337：返回 [不偷, 偷]。
- 0968：返回 0=未覆盖, 1=有摄像头, 2=已覆盖。

### 3.4 拓扑排序模板

```text
入度数组 + 邻接表
队列放入度为 0 的节点
while 队列非空:
    取出节点，加入结果
    遍历邻居，入度减 1
    入度为 0 则入队
```

- 0207：结果数量不等于节点数则有环。
- 0210：直接返回拓扑序。

### 3.5 回溯去重模板

```text
排序
dfs(start):
    for i in range(start, n):
        if i > start and nums[i] == nums[i-1]: continue
        选择 nums[i]
        dfs(i + 1)
        撤销选择
```

### 3.6 区间 DP 模板

```text
for length in range(2, n + 1):
    for i in range(n - length + 1):
        j = i + length - 1
        dp[i][j] = max/min(选择左端, 选择右端, 枚举分割点)
```

- 0486：`max(nums[i] - dp[i+1][j], nums[j] - dp[i][j-1])`
- 0312：枚举最后戳破的气球。

## 5. 后记

1. 先看“核心题族”表格，回忆每族的状态定义。
